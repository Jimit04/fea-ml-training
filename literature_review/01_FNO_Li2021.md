# Fourier Neural Operator (FNO) - Li et al., 2021

**arXiv:** https://arxiv.org/abs/2010.08895
**DOI:** 10.48550/arXiv.2010.08895
**Status:** Published in ICLR 2021

## Summary

FNO learns mappings between infinite-dimensional function spaces by parameterizing the integral kernel directly in **Fourier space**. This enables learning operators that generalize across different resolutions and discretizations.

## Key Innovation

Traditional neural networks map finite vectors to finite vectors. FNO learns **operators** that map functions to functions:

```
Classical: params (4-dim) → MLP → displacement field (756-dim for fixed mesh)
FNO: params (function space) → Fourier layers → field (any resolution)
```

## Architecture

1. **Input Lifting**: Embed input function onto a grid (e.g., parameters + spatial coordinates)
2. **Fourier Layers**: Apply element-wise multiplication in Fourier space
   - Transform to Fourier domain
   - Multiply by learned weight matrix ("kernel")
   - Inverse FFT back to physical space
   - Apply nonlinearity (activation)
3. **Repeat 4-6 times** with residual connections
4. **Output Projection**: Decode to output field

## Why It Works for Your Problem

### **Mesh Independence**

- Trained on grid of any size (e.g., 21×6×6)
- Can **super-resolve** to finer grids (30×8×8) at inference with zero additional training
- Can also work on coarser grids

### **Resolution Agnostic**

- FNO doesn't encode mesh resolution in its weights
- The Fourier transform treats different resolutions as different samplings of the same function

### **Mathematical Elegance**

Learning in Fourier space = learning the physics in frequency domain

- Low frequencies: overall beam deformation (most important)
- High frequencies: local stress concentrations

## Limitations for Your Use Case

1. **Structured Grids Only**: Requires regular rectangular grids (your beam is structured, so ✓)
2. **Resolution Mismatch**: Works best when train/test resolutions are similar
3. **No Irregular Meshes**: Can't handle unstructured/tetrahedral meshes directly

## Implementation Considerations

- **Input Format**: Flatten grid to 1D or process as 3D tensor (coordinate + value grids)
- **Fourier Transform**: Use FFT (fast on regular grids)
- **Computation**: O(N log N) per layer, very efficient for large fields
- **Framework**: Usually implemented in JAX or PyTorch

## Comparison to Your Current GCN

## When to Use

✅ **Use FNO if**:

- You have structured, regular meshes
- You want super-resolution capability
- Your geometries can be discretized on regular grids

❌ **Don't use FNO if**:

- You need unstructured mesh support
- You need to handle irregular geometries (e.g., cutouts, holes)
